Storybird 설정·음성·단축키 구조

이 문서는 공유 음성 환경을 Settings로 옮기고, 프로젝트 내레이션과 로컬 단축키를 분리한 흐름을 설명한다.

핵심 용어

장치 UID
재실행이나 재연결 뒤에도 같은 마이크를 찾기 위한 안정 식별자다.
시스템 기본 입력
macOS가 현재 기본 마이크로 선택한 장치다.
로컬 단축키
Storybird가 활성 앱일 때만 처리하는 키 조합이다. 전역 키 감시가 아니다.
프로젝트 소유 내레이션
프로필과 별개로 프로젝트가 소유하는 문장별 WAV와 시간축 레이어다.
샘플 정규화
장치 원본 포맷을 프로필용 24kHz mono 16-bit WAV로 변환하는 처리다.

녹음이 시작되면 그 세션의 장치는 고정된다. Settings에서 장치를 바꿔도 진행 중인 WAV는 바뀌지 않고 다음 안내 녹음부터 새 선택을 사용한다.

단축키 흐름

    Match --> Enabled{"대응 UI 작업이 현재 가능한가?"}
    Enabled -- 아니오 --> Noop["상태 변경 없음"]
    Enabled -- 예 --> Action["기존 작업 흐름 실행"]

단축키는 새 프로젝트, 녹화 시작·중지, 가져오기, 내보내기만 다룬다. 다른 앱이 활성일 때는 처리하지 않으며 Accessibility나 Input Monitoring 권한을 추가하지 않는다.

실패 시 보존되는 것

  • 선택한 마이크가 없더라도 저장된 UID는 지우지 않는다.
  • 선택 장치와 시스템 기본 장치를 모두 열 수 없으면 프로필을 만들지 않는다.
  • 10초 미만 WAV나 쓰기 실패 WAV는 프로필 저장소에 들어가지 않는다.
  • 잘못되거나 중복된 단축키는 기존 유효 조합을 덮어쓰지 않는다.
  • 비활성 작업의 단축키는 프로젝트·녹화·내보내기 상태를 바꾸지 않는다.
