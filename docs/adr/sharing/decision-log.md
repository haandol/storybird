# Decision Log: sharing

이 문서는 sharing 카테고리의 주요 결정 변경 이력이다. 각 ADR 본문은 현재
상태만 서술하고, 주요 전환의 시간축은 여기에 역순으로 쌓는다.

## 2026-09-10 — 분리 제작과 오디오 레이어 편집

- **Current ADR**: [0001-layered-video-export](./0001-layered-video-export.md)
- **Change type**: requirement rule change
- **What**: 순차 내레이션 중심 제작 → 독립 오디오 자산과 중첩 레이어를 사용하는 제작.
- **Why**: 대본에서 TTS를 생성하는 에이전트가 음성 길이에 맞춰 영상과 여러 레이어를 완성해야 한다.

## 2026-09-08 — 가져온 영상의 기본 음성을 선택적 AAC 출력으로 보존

- **현재 ADR**: [layered-video-export](./0001-layered-video-export.md)
- **변경 유형**: 요구사항 규칙 변경
- **무엇이**: 모든 결과의 오디오 트랙이 `0개`인 출력에서, 기본 음성이 있는 원본은 편집된
  클립 시간축의 AAC 트랙 `1개`를 출력하고 무음 원본은 오디오 트랙 `0개`를 유지하는 출력으로
  확장했다.
- **왜**: 사용자가 말하며 만든 제품 소개 영상을 가져와도 최종 공유 MP4에서 설명 음성을
  보존해야 한다.

## 2026-09-05 — 전체 편집 타임라인과 MCP 작업 수명주기를 출력 계약에 포함

- **현재 ADR**: [layered-video-export](./0001-layered-video-export.md)
- **변경 유형**: 아키텍처
- **무엇이**: 기본 클릭·자막 합성에서, 비파괴 클립과 Click Cue·데모 효과·카드를 포함한
  타임라인 합성 및 검증·진행률·취소·종료 상태를 가진 MCP 내보내기 작업으로 확장했다.
- **왜**: 사람과 외부 MCP 클라이언트가 같은 완성도 검증과 파일 안전 계약으로 최종 MP4를
  만들어야 한다.

## 2026-09-05 — 정적 HTML 공유를 합성 MP4 출력으로 교체

- **현재 ADR**: [layered-video-export](./0001-layered-video-export.md)
- **변경 유형**: 채택 대안 교체
- **무엇이**: HTML, JSON과 PNG 자산을 내보내던 결과물을, 원본 영상과 시간 기반 레이어를
  합성한 무음 H.264 MP4 한 파일로 바꿨다.
- **왜**: 결과물이 일반 영상 플레이어와 업로드 서비스에서 실제 화면 움직임을 그대로
  재생해야 한다.
- **무효가 된 것**: 인터랙티브 정적 플레이어와 웹 접근성을 공유 결과물의 중심에 두던 계약.

## 2026-09-05 — 인증된 로컬 제어에서 정적 내보내기 허용

- **현재 ADR**: [layered-video-export](./0001-layered-video-export.md)
- **변경 유형**: 아키텍처
- **무엇이**: UI 폴더 선택으로만 실행하던 정적 내보내기를, Storybird 앱이 처리하는 인증된
  로컬 요청에서도 같은 안전 계약으로 실행한다.
- **왜**: companion에 파일 쓰기 권한이나 exporter 구현을 복제하지 않고 자동화된 데모 준비를
  지원해야 한다.

## 2026-09-02 — 정적 플레이어에 텍스트 오버레이 계약 보존

- **현재 ADR**: [layered-video-export](./0001-layered-video-export.md)
- **변경 유형**: 아키텍처
- **무엇이**: 화면 캡처와 기본 화면 캡션을 내보내던 플레이어를 클릭포인트 캡션과 상단·하단
  화면 자막의 위치·색상·투명도까지 보존하는 플레이어로 확장했다.
- **왜**: 편집기에서 만든 안내의 의미와 가독성이 오프라인 정적 데모에서도 동일해야 한다.
## 2026-09-08 — 프로젝트 내레이션을 결과 AAC에 믹싱

- **현재 ADR**: [layered-video-export](./0001-layered-video-export.md)
- **변경 유형**: 요구사항 규칙 변경
- **무엇이**: 원본 오디오만 선택적으로 출력하던 MP4에 프로젝트 소유 내레이션을 지정 시각과
  음량으로 믹싱해 AAC 트랙 하나로 출력한다.
- **왜**: 본인 음성으로 생성한 서비스 소개 내레이션을 일반 플레이어에서 함께 재생해야 한다.
