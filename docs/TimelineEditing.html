Storybird의 간단한 영상 편집 흐름

원본 MP4는 바꾸지 않고, 프로젝트에 “어느 구간을 어떤 순서와 속도로 재생할지”를 저장합니다. UI와 MCP(Model Context Protocol, 외부 도구 연결 규약)는 같은 편집 규칙을 사용합니다.

편집 제안

모든 블록은 같은 가로 시간축에 놓입니다. 세로 재생 헤드가 현재 프리뷰 시각을 나타내며, 눈금자를 클릭하거나 드래그하면 해당 시각으로 이동합니다.

사람이 편집하는 순서

  1. Video 트랙의 클립을 선택합니다.
  2. 재생 헤드를 수정할 위치로 옮깁니다.
  3. Split으로 둘로 나누거나, Trim으로 앞·뒤 구간을 제거합니다.
  4. 1× / 2× / 4× 속도를 고르거나 필요 없는 클립을 삭제합니다.
  5. Click Cue와 자막이 같은 장면에 남아 있는지 프리뷰로 확인합니다.

MCP 편집에서 기억할 점

변경 명령에는 마지막으로 읽은 expected_revision을 넣습니다. 사람이 먼저 수정해 revision이 달라졌다면 Storybird는 MCP 요청을 거부합니다. MCP 클라이언트는 최신 프로젝트를 다시 읽고 편집 위치를 다시 계산해야 합니다.

제공 명령: storybird_split_clip, storybird_trim_clip, storybird_delete_clip, storybird_move_clip, storybird_set_clip_speed, storybird_insert_freeze.
